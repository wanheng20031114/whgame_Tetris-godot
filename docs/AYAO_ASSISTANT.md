# 阿咬助手

阿咬首先在回放（Replay）系统中实验，按落子步骤给出简短分析、建议或表扬。当前使用本地教练逻辑，不发送棋盘、操作记录或任何数据到外部服务。远程 AI provider 尚未启用；填写配置也不会触发网络请求。后续可复用这套教练接口，在单人马拉松中选择合适时机帮助新手。

## 回放中的行为

右侧时间线上方显示阿咬：一条本步观察和一条下一步建议。前后步、首尾步、拖动时间线与切换对局都会更新点评；空回放恢复欢迎状态。收起后继续跟踪当前步骤，展开即可看到最新点评。

有参考方案时可以直接从助手打开现有的落点演示。方案预览是对比工具，阿咬仍然点评玩家真正走过的那一步，不把模拟中的未来落点当成玩家记录。面板支持中文、英文、日文和深浅主题，角色待机使用场景中的 `AnimationPlayer`，回应使用可取消的 Tween，快速切步不会叠加动画。

新点评先逐字显示观察，再显示建议，使用 `arc-nice` NPC 对话的 35 ms 字间节奏、120 ms 逗号停顿和 220 ms 句末停顿。文本始终先完成排版，因此显示期间不会反复换行或推动下方组件。原提示音通过场景内的 `AudioStreamRandomizer` 随机微调音高和音量；空格、标点不发声，并遵循 Master 总音量与静音设置。来源记录在 `audio/AYAO_SOURCE.md`。

点击点评区域可立即显示全文并停止声音。快速切步会取消旧内容；重复刷新同一步、切换方案和主题不会重播。收起或隐藏面板会停止逐字效果，展开后直接显示最新全文；切换语言和清空对局也不会继续播放旧语言或旧对局的字符。欢迎文字直接显示，不主动发声。可复用控制器位于 `scripts/ui/dialogue_typewriter.gd`，Label 与音频节点在原生场景中连接。

`AyaoCoach.analyze_step(snapshot, previous, ai_detail, recommendation)` 是与场景无关的纯函数。返回 `kind`、标题/观察/建议的翻译键与参数，以及可序列化的 `facts`。事实只保留实际存在的数据：消行后的棋盘和地形指标、连续步骤的空洞/高度变化、消行与攻击记录、有效的 AI 分差及参考方案可用性。旧记录只有落地棋盘时会先解析满行；缺失棋盘或未知评分不会被包装成“最佳落子”。

本地优先提醒危险高度和新增空洞，再反馈挖洞改善、全清、T-Spin、四消、连击、攻击、参考评分和普通地形。它是简短启发式教练，不替代现有搜索分析器。

## 后续 API 与马拉松接入点

`ReplaySystem._refresh_assistant()` 目前调用本地教练，再通过 `AyaoAssistantPanel.present_review(...)` 展示。后续 provider 可以使用同一份 `facts` 和步骤标识组织请求；回包需要同时核对对局与步骤，防止快速切步后出现旧回复。API 回复应保持“观察 + 一个建议”的长度，并明确区分本地与远程来源。

马拉松可在锁定与消行结束后复用 `AyaoCoach`，由游戏侧另行决定新手提示的触发时机、间隔和开关。本轮没有给实时对局增加每步弹出的提示。

角色原图与来源见 `assets/assistant/SOURCE.md`；立绘保持原始文件。

## 本地配置

项目根目录已预留 `.env`，三个值均留空：

```dotenv
AI_API_KEY=
AI_API_BASE_URL=
AI_MODEL=
```

后续接入服务时填写 API 密钥、服务地址和模型名称，不需要改游戏脚本。服务商和请求协议会在真正接入时明确，目前不绑定任何供应商。`.env.example` 是可提交的空值模板。

`AssistantConfig.load_configuration()` 只在 Godot 编辑器或调试构建中读取项目 `.env`，并读取同名进程环境变量。进程环境变量优先，包括显式设置的空值。读取器只接受上述三个键，支持空行、整行 `#` 注释和成对的单/双引号；不执行变量替换或脚本。缺少文件或未填写完整配置时视为尚未配置，不影响本地教练。

配置读取器不输出密钥、不保存密钥副本，也不发起请求。调用方不得将配置对象写入日志、回放或玩家存档。

## Git 与发布

`.gitignore` 排除了 `.env` 和 `.env.*`，仅允许 `.env.example` 模板。所有当前导出预设也显式排除了这些文件，避免将本地配置打入游戏资源包。

共享 API 密钥不能随客户端发布。正式联网版本应由服务端代理持有密钥，客户端通过受控、可限流的游戏接口获取助手回复。服务端代理与远程调用将在后续接入 API 时实现。
